## Specific disagreements and source defects to disclose

1. Elder PDF170/154 says normal potential reward/risk should exceed2:1, with strong-signal exceptions. Project >=1.0 acceptance is a different, existing parameter. Do not call1.0 Elder-supported, and do not silently change the project.
2. Elder PDF95/79 suggests pairedEMAs about2:1; project7/25 is not that ratio. The value-zone principle is supported; numeric implementation is not an exact Elder method.
3. Vaida PDF117/100 asserts24h exchange permits TR=H-L because prior close equals next open. This is only equivalent when prior close lies within current high-low; 24h trading by itself is insufficient. Full three-term formula PDF116/99 and ElderPDF106/90 is defensible. Flag the text's overgeneralization; do not silently repeat it.
4. Vaida PDF125/108 fourth bullet labels lower price highs+higher oscillator highs as hidden bullish. The same page's Figure4.13 places it under Bearish. Verified visually in tmp/pdfs/book_evidence/vaida-125.png. Do not copy the erroneous bullet.
5. Leahy PDF82/74 divergence labels conflict with ElderPDF117/101: Leahy calls indicator new highs+price new lows bearish and inverse bullish. Do not use these descriptions as authoritative signal rules. LeahyPDF83/75 ATR discussion links risingATR with possible reversal/fallingATR with continuation; this is contextual and not directional guarantee.
6. Vaida PDF115/98 RSI recursive numerator uses previous average*n+current, while usual Wilder recursion uses n-1. This needs independent formula verification if implementing; avoid copying this formula. Also statement overbought is bound to be sold is too categorical relative to Elder's trend caveat.
7. VaidaPDF187–188/170–171SHIELD suggests switching stopped trades into investments with drawbacks. Excluded from LONG leveraged futures0–4h scope, conflicts with fixed-stop/horizon project discipline.

## Scientific verification boundary

The checked books give educational methods and examples. They do NOT establish a tested guarantee for the proposed intraday futures selector, precise timing, or future15m/1h/4h min/max. Existing project numeric gates must remain visibly labeled project parameters awaiting strategy-specific empirical evaluation. A statistically calibrated model for future path extremes needs additional explicit statistical source support and out-of-sample validation. ATR channels/support-resistance are scenario references or targets, not probability-calibrated extrema. Treat target-hitting order and costs separately from max/min forecasts; favorable future maximum alone cannot establish executable profitability.
